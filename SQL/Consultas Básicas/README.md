# Consultas Básicas
São maneiras de consultar dados em um banco de dados.

- `SELECT`: nos permite definir quais colunas você quer ver. É possível usar ele combinando com outros atributos.

- `FROM`: Especifica de qual tabela os dados vão vir.

- `WHERE`: Filtra as linhas com base em condições (como `>, <, >= , <=, =`).

- `ORDER BY`: Ordena os resultados em ordem crescente `ASC` ou decrescente `DESC`.

- `LIMIT`: Restringe a quantidade de linhas retornadas.

É possível combinar condições no `WHERE` com operadores lógicos. (`AND`, `OR`, `LIKE`)
